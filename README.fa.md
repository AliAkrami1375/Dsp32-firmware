# Dsp32 — فرمویر

**ایمیج‌های آماده‌ی فلش برای سیستم‌عامل دسکتاپ وب Dsp32.**

هر ESP32 را به یک کامپیوتر مستقل تبدیل کنید، با هات‌اسپات وای‌فای خودش
و یک دسکتاپ کامل به سبک ویندوز ۱۱ داخل مرورگر.

## چه چیزی به دست می‌آورید

Dsp32 را فلش کنید و برد هات‌اسپات وای‌فای خودش را بالا می‌آورد، یک captive
portal اجرا می‌کند، و یک دسکتاپ کامل به هر گوشی یا لپ‌تاپی که وصل شود تحویل
می‌دهد — بدون نصب هیچ اپی، بدون نیاز به اینترنت. کل رابط کاربری داخل خود
فرمویر پخته شده است.

| | |
|---|---|
| **دسکتاپ روی هات‌اسپات** | به AP وصل شوید، روی بیشتر دستگاه‌ها دسکتاپ خودش باز می‌شود |
| **شناسایی خودکار سخت‌افزار** | اسپلش بوت چیپ، هسته‌ها، فرکانس، heap، PSRAM، فلش، کارت SD و دوربین را بررسی می‌کند و گزارش می‌دهد چه پیدا کرده |
| **دوازده اپ** | فایل منیجر، This PC، ترمینال، ویرایشگر متن، دوربین، تسک منیجر، ماشین حساب، فایروال، مدیر شبکه، اپ استودیو، تنظیمات، تصاویر |
| **پنجره‌های واقعی** | کشیدن، تغییر اندازه، چسباندن به نصف صفحه، بیشینه، کمینه، گروه‌بندی تسک‌بار، منوی راست‌کلیک |
| **ذخیره‌سازی** | فلش داخلی به‌علاوه‌ی کارت SD — آپلود، دانلود، تغییر نام، حذف، کشیدن و رها کردن |
| **دوربین** | استریم زنده‌ی MJPEG و عکس‌برداری، روی بردهایی که دوربین دارند |
| **شبکه و فایروال** | تغییر مشخصات هات‌اسپات، اتصال به روتر بالادست، بلاک کردن کلاینت با MAC |
| **توسعه‌پذیر** | یک فایل `.js` روی دستگاه بگذارید تا به یک اپ دسکتاپ تبدیل شود |

## برد خود را انتخاب کنید

| برد شما | دانلود | دوربین | کارت SD |
|---|---|---|---|
| ESP32 معمولی (DevKit، WROOM، WROVER) | [`esp32`](firmware/esp32/) | — | SPI، پین CS شماره ۵ |
| AI-Thinker ESP32-CAM | [`esp32cam`](firmware/esp32cam/) | ✅ OV2640 | ✅ SDMMC |
| ESP32-S2 | [`esp32s2`](firmware/esp32s2/) | — | SPI |
| ESP32-S3 معمولی | [`esp32s3`](firmware/esp32s3/) | — | SPI |
| Seeed XIAO ESP32S3 Sense | [`xiao_s3_sense`](firmware/xiao_s3_sense/) | ✅ OV2640 | ✅ SPI، پین CS شماره ۲۱ |
| ESP32-C3 | [`esp32c3`](firmware/esp32c3/) | — | SPI |
| ESP32-C6 | [`esp32c6`](firmware/esp32c6/) | — | SPI |

داخل هر پوشه:

| فایل | چیست |
|---|---|
| `dsp32-<variant>-merged.bin` | **همین را بردارید.** بوت‌لودر + جدول پارتیشن + اپلیکیشن در یک ایمیج. فلش روی آفست `0x0`. |
| `bootloader.bin` و `partition-table.bin` و `dsp32-<variant>.bin` | همان سه بخش به‌صورت جداگانه، برای ابزارهایی که این شکل را می‌خواهند. |

صحت هر دانلود را با [`SHA256SUMS.txt`](SHA256SUMS.txt) بررسی کنید.

## فلش کنید

**راه سریع** — این مخزن را کلون کنید و بگذارید اسکریپت خودش ایمیج و آفست و
پورت سریال را پیدا کند:

</div>

```bash
git clone https://github.com/AliAkrami1375/Dsp32-firmware.git
cd Dsp32-firmware
./flash.sh
```

<div dir="rtl">

**یا دستی انجامش دهید:**

</div>

```bash
pip install esptool
esptool.py -p /dev/ttyUSB0 -b 460800 write_flash 0x0 dsp32-esp32-merged.bin
```

<div dir="rtl">

روی ویندوز پورت شبیه `COM5` است و روی مک شبیه `/dev/cu.usbserial-0001`.

رابط گرافیکی ترجیح می‌دهید؟ از **ESP Flash Download Tool** رسمی Espressif
استفاده کنید، یا مستقیم از داخل کروم در [esp.huhn.me](https://esp.huhn.me/)
بدون نصب هیچ چیزی فلش کنید.

**تنظیماتی که هر ابزاری می‌پرسد:** SPI mode روی **DIO** · سرعت **۴۰ مگاهرتز** ·
اندازه‌ی فلش **۴ مگابایت** · baud برابر **460800**

**آدرس‌های حافظه** — فقط وقتی لازم است که سه فایل را جداگانه فلش می‌کنید. آفست
بوت‌لودر بین چیپ‌ها فرق می‌کند و اشتباه زدنش رایج‌ترین دلیل بوت‌لوپ است:

| چیپ | bootloader.bin | partition-table.bin | اپلیکیشن |
|---|---|---|---|
| ESP32 و ESP32-S2 | `0x1000` | `0x8000` | `0x10000` |
| ESP32-S3 و C3 و C6 | `0x0` | `0x8000` | `0x10000` |

ایمیج merged کلاً دور همه‌ی اینها می‌زند — روی هر چیپی سر `0x0` می‌رود.

📖 **[راهنمای کامل فلش](docs/FLASHING.fa.md)** — قدم‌به‌قدم برای هر ابزار،
سیم‌کشی ESP32-CAM، نحوه‌ی بردن برد به حالت دانلود، و رفع اشکال.

## اولین بوت

۱. به شبکه‌ی وای‌فای **`Dibachain`** با رمز **`dsp32pass`** وصل شوید
۲. بیشتر دستگاه‌ها خودشان دسکتاپ را باز می‌کنند (captive portal). در غیر این
   صورت آدرس **http://10.3.2.1** یا **http://dsp32.local** را باز کنید

اولین بوت یک صفحه‌ی اسپلش نشان می‌دهد که سخت‌افزار را بررسی می‌کند و گزارش
می‌دهد چه چیزی پیدا کرده، بعد دسکتاپ ظاهر می‌شود.

بعد از آن همه چیز از اپ تنظیمات قابل تغییر است: نام و رمز هات‌اسپات، تم، رنگ
accent، والپیپر، اتصال وای‌فای بالادست و ذخیره‌سازی.

## امتحان بدون سخت‌افزار

کل دسکتاپ روی کامپیوتر خودتان در مقابل یک دستگاه شبیه‌سازی‌شده اجرا می‌شود:

</div>

```bash
git clone https://github.com/AliAkrami1375/Dsp32.git
cd Dsp32
python3 simulator/dsp32_sim.py
# باز کنید: http://localhost:8000
```
