# فلش کردن Dsp32

هر چیزی که برای نصب Dsp32 روی برد لازم دارید، با هر ابزاری که ترجیح می‌دهید.

[English](FLASHING.md)

---

## کدام فایل را لازم دارم؟

هر ریلیز برای هر واریانت دو نوع ایمیج دارد:

| فایل | چه وقت استفاده کنید |
|---|---|
| `dsp32-<variant>-merged.bin` | **پیشنهادی.** بوت‌لودر + جدول پارتیشن + اپلیکیشن در یک فایل. آن را روی آفست `0x0` فلش کنید و تمام — هیچ آدرسی لازم نیست به خاطر بسپارید. |
| `bootloader.bin` و `partition-table.bin` و `dsp32-<variant>.bin` | وقتی سه بخش را جدا می‌خواهید، یا ابزارتان همین شکل را می‌خواهد (ESP Flash Download Tool، سناریوهای OTA). |

واریانت متناسب با برد خود را انتخاب کنید:

| برد شما | واریانتی که باید دانلود کنید |
|---|---|
| ESP32 DevKit / WROOM / WROVER معمولی | `esp32` |
| AI-Thinker ESP32-CAM | `esp32cam` |
| بردهای ESP32-S2 | `esp32s2` |
| ESP32-S3 DevKit معمولی | `esp32s3` |
| Seeed XIAO ESP32S3 Sense | `xiao_s3_sense` |
| بردهای ESP32-C3 | `esp32c3` |
| بردهای ESP32-C6 | `esp32c6` |

## تنظیمات فلش

اینها همان تنظیماتی است که Dsp32 با آن بیلد شده. هر ابزاری که این مقادیر را از
شما بپرسد، دقیقاً همین‌ها را می‌خواهد:

| تنظیم | مقدار |
|---|---|
| SPI mode | **DIO** |
| SPI speed | **۴۰ مگاهرتز** |
| Flash size | **۴ مگابایت** (32 Mbit) |
| Baud rate | **460800** (اگر آپلود شکست خورد به 115200 کم کنید) |

> روی بردهایی با فلش ۸ یا ۱۶ مگابایت هم کار می‌کند — Dsp32 فقط از ۴ مگابایت اول
> استفاده می‌کند. اندازه‌ای **کمتر** از ۴ مگابایت انتخاب نکنید.

### آدرس‌های حافظه

فقط وقتی لازم است که سه فایل را جداگانه فلش می‌کنید. **آفست بوت‌لودر بین
چیپ‌ها فرق می‌کند** — رایج‌ترین اشتباه دقیقاً همین است:

| چیپ | bootloader.bin | partition-table.bin | dsp32-\<variant\>.bin |
|---|---|---|---|
| ESP32 | `0x1000` | `0x8000` | `0x10000` |
| ESP32-S2 | `0x1000` | `0x8000` | `0x10000` |
| ESP32-S3 | `0x0` | `0x8000` | `0x10000` |
| ESP32-C3 | `0x0` | `0x8000` | `0x10000` |
| ESP32-C6 | `0x0` | `0x8000` | `0x10000` |

ایمیج merged همه‌ی اینها را از قبل داخل خودش دارد، برای همین روی هر چیپی
سر آدرس `0x0` می‌رود.

## روش ۱ — esptool (هر سیستم‌عاملی، پیشنهادی)

ابزار خط فرمان رسمی Espressif. روی ویندوز، مک و لینوکس کار می‌کند.

```bash
pip install esptool
```

**فایل merged — راه ساده:**

```bash
esptool.py -p /dev/ttyUSB0 -b 460800 write_flash 0x0 dsp32-esp32-merged.bin
```

روی ویندوز پورت شبیه `COM5` است و روی مک شبیه `/dev/cu.usbserial-0001`.

**سه فایل جداگانه** (به آفست بوت‌لودر مخصوص هر چیپ دقت کنید):

```bash
# ESP32 / ESP32-S2
esptool.py -p /dev/ttyUSB0 -b 460800 --chip esp32 write_flash \
  --flash_mode dio --flash_freq 40m --flash_size 4MB \
  0x1000  bootloader.bin \
  0x8000  partition-table.bin \
  0x10000 dsp32-esp32.bin

# ESP32-S3 / C3 / C6 — بوت‌لودر می‌رود روی 0x0
esptool.py -p /dev/ttyUSB0 -b 460800 --chip esp32s3 write_flash \
  --flash_mode dio --flash_freq 40m --flash_size 4MB \
  0x0     bootloader.bin \
  0x8000  partition-table.bin \
  0x10000 dsp32-esp32s3.bin
```

اگر جای فرمویر دیگری را می‌گیرید، یا برد بعد از فلش رفتار عجیبی دارد،
**اول کل چیپ را پاک کنید:**

```bash
esptool.py -p /dev/ttyUSB0 erase_flash
```

این کار تنظیمات ذخیره‌شده‌ی وای‌فای را هم پاک می‌کند، پس هات‌اسپات به حالت
کارخانه یعنی `Dibachain` / `dsp32pass` برمی‌گردد.

## روش ۲ — ESP Flash Download Tool (رابط گرافیکی ویندوز)

ابزار رسمی ویندوزی Espressif. از
[espressif.com/en/support/download/other-tools](https://www.espressif.com/en/support/download/other-tools)
دانلود کنید.

۱. اجرا کنید و **ESP32 DownloadTool** را انتخاب کنید (یا ESP32-S3 / C3 / C6
   متناسب با چیپ خودتان)، سپس حالت **Develop**.

۲. در ردیف‌های فایل، ایمیج‌ها و آدرس‌هایشان را وارد کنید و تیک هر ردیف را بزنید:

   | ✓ | فایل | آدرس |
   |---|---|---|
   | ☑ | `dsp32-esp32-merged.bin` | `0x0` |

   یا با سه فایل جداگانه روی ESP32:

   | ✓ | فایل | آدرس |
   |---|---|---|
   | ☑ | `bootloader.bin` | `0x1000` |
   | ☑ | `partition-table.bin` | `0x8000` |
   | ☑ | `dsp32-esp32.bin` | `0x10000` |

۳. تنظیمات SPI را در پایین صفحه ست کنید:
   - **SPI SPEED**: `40MHz`
   - **SPI MODE**: `DIO`
   - **FLASH SIZE**: `32Mbit` (یعنی ۴ مگابایت)
   - تیک **DoNotChgBin** را نزنید

۴. پورت **COM** را انتخاب و **BAUD** را روی `460800` بگذارید.

۵. اگر برد فرمویر دیگری داشت یک بار **ERASE** بزنید، بعد **START**.

۶. تا **FINISH** صبر کنید، سپس دکمه‌ی ریست برد را بزنید.

## روش ۳ — مرورگر (بدون نصب هیچ چیزی)

در کروم یا اِج، [esp.huhn.me](https://esp.huhn.me/) یا
[ESP Web Tools](https://espressif.github.io/esptool-js/) را باز کنید
(Web Serial در فایرفاکس و سافاری موجود نیست).

۱. روی **Connect** بزنید و پورت سریال برد را انتخاب کنید.
۲. فایل `dsp32-<variant>-merged.bin` را روی آدرس `0x0` اضافه کنید.
۳. **Program** را بزنید.

## بردن برد به حالت دانلود

بیشتر بردهای امروزی این کار را خودکار از طریق USB انجام می‌دهند. اگر فلش با
خطای *«Failed to connect… Wrong boot mode detected»* شکست خورد، دستی انجامش
دهید:

۱. دکمه‌ی **BOOT** (که گاهی **IO0** یا **GPIO0** برچسب خورده) را نگه دارید.
۲. در حالی که BOOT را نگه داشته‌اید، یک ضربه به **RESET** (**EN**) بزنید.
۳. BOOT را رها کنید. برد حالا منتظر آپلود فرمویر است.
۴. فلش را شروع کنید و در پایان دوباره RESET بزنید.

**ESP32-CAM** نه پورت USB دارد نه دکمه. به یک مبدل USB-to-TTL نیاز دارید:

| ESP32-CAM | مبدل USB-TTL |
|---|---|
| 5V | 5V |
| GND | GND |
| U0R (GPIO3) | TX |
| U0T (GPIO1) | RX |
| **IO0** | **GND** — فقط هنگام فلش |

قبل از وصل کردن برق، `IO0` را به `GND` وصل کنید، فلش کنید، بعد این اتصال را
بردارید و برد را خاموش‌روشن کنید.

## اولین بوت

بعد از فلش، یک مانیتور سریال با **115200 baud** باز کنید تا بالا آمدنش را ببینید:

```bash
idf.py -p /dev/ttyUSB0 monitor      # اگر ESP-IDF نصب دارید
```

باید این را ببینید:

```
  ____            _____ ___
 |  _ \  ___ _ __|___ /|_  )
 | | | |/ __| '_ \ |_ \ / /
 | |_| |\__ \ |_) |__) /___|
 |____/ |___/ .__/____/
            |_|  v1.0.0 — web desktop OS

I (612) dsp32_fs: flash=ok sd=-
I (734) dsp32_wifi: hotspot "Dibachain" up at 10.3.2.1
I (741) dsp32_dns: captive DNS on :53 -> 10.3.2.1
I (802) dsp32_http: desktop on http://10.3.2.1/ (20 embedded assets)
I (805) dsp32: ready — connect to the hotspot and open http://10.3.2.1
```

بعد، از گوشی یا لپ‌تاپ:

۱. به شبکه‌ی وای‌فای **Dibachain** با رمز **dsp32pass** وصل شوید
۲. بیشتر دستگاه‌ها خودشان دسکتاپ را باز می‌کنند (captive portal). اگر نشد،
   آدرس **http://10.3.2.1** یا **http://dsp32.local** را باز کنید

اولین بوت یک صفحه‌ی اسپلش نشان می‌دهد که سخت‌افزار را شناسایی می‌کند و
گزارش می‌دهد چه چیزی پیدا کرده، بعد دسکتاپ ظاهر می‌شود.

## رفع اشکال

**«Failed to connect to ESP32: No serial data received»**
برد در حالت دانلود نیست، یا درایور نصب نشده. توالی دستی BOOT/RESET بالا را
امتحان کنید. روی ویندوز بسته به چیپ USB بردتان درایور
[CP210x](https://www.silabs.com/developers/usb-to-uart-bridge-vcp-drivers) یا
[CH340](https://www.wch-ic.com/downloads/CH341SER_ZIP.html) را نصب کنید.

**«A fatal error occurred: Timed out waiting for packet header»**
سرعت را به `115200` کم کنید و از کابل USB کوتاه‌تر یا بهتری استفاده کنید. بعضی
کابل‌ها فقط شارژی هستند و اصلاً دیتا منتقل نمی‌کنند.

**فلش موفق است ولی برد مدام ریست می‌شود**
به احتمال زیاد آفست بوت‌لودر را اشتباه زده‌اید — روی ESP32/S2 باید `0x1000`
باشد و روی S3/C3/C6 باید `0x0`. یک بار `erase_flash` بزنید و به‌جایش ایمیج
merged را روی `0x0` فلش کنید.

**هات‌اسپات اصلاً ظاهر نمی‌شود**
لاگ سریال را ببینید. اگر درست بعد از بنر متوقف می‌شود، احتمالاً برد افت ولتاژ
دارد: رادیوی وای‌فای در لحظات اوج تا ۵۰۰ میلی‌آمپر می‌کشد. از یک منبع ۵ ولت
مناسب یا هاب USB برق‌دار استفاده کنید، نه پورت لپ‌تاپ با کابل بلند.

**دسکتاپ بالا می‌آید ولی کارت SD نشان داده نمی‌شود**
ایمیج‌های عمومی آماده روی همه‌ی بردها SD را فعال نمی‌کنند چون سیم‌کشی فرق
می‌کند. با پین‌های خودتان از سورس بیلد بگیرید:
`idf.py menuconfig` ← **Dsp32 Configuration** ← **SD card interface**.

**رمز هات‌اسپاتی که گذاشته بودم را فراموش کرده‌ام**
`esptool.py -p <port> erase_flash` بزنید و دوباره فلش کنید — این کار NVS را
پاک می‌کند و `Dibachain` / `dsp32pass` را برمی‌گرداند.
